Add bounded rate limits for reset requests and verification attempts without adding a dependency. Clear the stored pending code and expiry when email delivery fails. Add a mail-sender injection seam for deterministic failure tests; mock it to reject and assert the stored code is cleared, without contacting SMTP. Extend temporary-store tests for generated-code shape, expiry, reuse rejection, equal known/unknown route responses, rate limiting, and mail failure. Preserve the full persisted auth store and do not alter schemas or unrelated routes.</action>
