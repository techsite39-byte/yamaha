## Trust Boundaries

| Boundary | Description |
|---|---|
| Authorized browser → protected overview API | Session and allowlist authorization must remain server-enforced; client state is not authority. |
| Backend data stores → overview projection | Missing, failed, or semantically ambiguous data must not be presented as confirmed business truth. |
